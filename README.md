# Tappy

App web in un solo file (`index.html`) per l'allenamento su tapis roulant: 36 programmi + allenamento manuale, video di scenario, guida vocale, cruscotto live, storico con obiettivi e Coach AI (Gemini), tracker GPS per percorsi reali, replay con vista "Nastro 3/4" e sfida comandata via Bluetooth FTMS, fascia cardio, backup su Google Drive e collegamento con **Nuvia** (diario alimentare).

Pubblicala su GitHub Pages (https) per usare Bluetooth, GPS, API Google e installazione come app. La guida completa è nella sezione ❓ dell'app.
